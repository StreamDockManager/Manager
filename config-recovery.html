Remaining issues

    Recover from a database backup

    Choose a backup to copy selected profiles or preview a full database restore. Copying profiles adds new copies. Restoring replaces the current database and requires separate confirmation.

    Restore the full database

    Use this when the current database cannot be opened, or when you need the complete saved database state rather than selected profiles.

        Restoring replaces the current database. Its previous contents are preserved separately; the selected backup is not changed. Devices and plugins stay stopped until you explicitly continue.

        Copy selected profiles

        The current database cannot be read, so individual profiles cannot be copied into it. Preview a full restore instead.

          The backup list or selected profiles could not be read or transferred. Choose Check again, then review and select the profiles again. No automatic retry or full restore will be performed.

          Invalid profiles cannot be selected. Profiles that refer to other profiles may need to be selected together. Existing profiles are never replaced.

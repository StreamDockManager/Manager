Profile parameters

Reusable values for this profile’s actions, with local overrides for each setup.

How to use parameters

Give a value a name, such as workspace , then use ${parameter.workspace} as the entire value of a supported action field. In a declared plugin setting, use {"$parameter":"workspace"} .

A portable default travels with the profile. Local overrides stay on this computer. The selected device’s override wins over the computer’s override, then the default.

Required parameters must have a value. Sensitive text uses the OS credential store instead of a portable default. Marking a value sensitive does not erase earlier history.

No parameters yet. Add one to reuse a path, URL, or other value across actions.

Background operation

Closing the desktop editor unloads its interface and keeps devices and actions running. Unsaved changes can be discarded or kept open for editing. Reopen the Device editor from the tray or launcher. On macOS, the Dock icon is hidden while the editor is closed. Use Quit in the tray menu to stop the runtime.

Profiles & portability

Profiles are validated and saved atomically by Rust. Validated recovery snapshots retain recent settings and workspace records.

Choose whether to include plugin action settings when exporting. Review parameter defaults and paths before sharing.

Device background

The default wallpaper follows your palette. Use PNG, JPEG, SVG, GIF or MP4 to set a custom background for the active profile.

FFmpeg is an optional fallback for MP4 imports. Prepared exports play without it. Clips: up to 16 MiB and 30 seconds.
